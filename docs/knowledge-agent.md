# 知识库与资料智能体：配置、使用和验收

适用分支：`feat/knowledge-agent-20260924`。本功能在现有 Java 单体、Vue 管理后台和 uni-app 小程序中运行，不需要新增微服务、消息队列或向量数据库。

## 1. 功能入口

### 管理后台

登录后打开左侧 **知识库与智能体**，依次完成：

1. **知识库与资料**：新建知识库，选择现有考试并填写名称。考试列表来自后端，不生成虚拟考试记录。
2. 上传 PDF、TXT 或 Markdown。上传后状态为 **待审核**，不会自动参与学员问答。同一知识库中的相同文件按 SHA-256 去重。
3. 打开 **预览原文**，检查提取文字、原 PDF 页码和解析警告。这里是实际入库文字，不是完整 PDF 版式预览。确认内容和使用权限后点击 **发布**。
4. **智能体配置**：填写名称、说明和辅导风格，关联 1 至 10 个同一考试的知识库。新建智能体默认停用，需显式启用。
5. **问答调试**：选择已启用智能体、新建会话并提问。调试使用当前管理员自己的会话，遵守与学员相同的发布状态、资料范围和 AI 配额规则。

知识库可以编辑名称和说明；所属考试不允许修改。存在资料或智能体关联时不能直接删除知识库。已有学习会话的智能体应停用而不是删除，以保留历史记录。

### 学员小程序

打开 **AI 助教 → 进入资料智能体**，选择智能体，恢复历史会话或新建会话。提问、继续追问后可以查看来源文件、PDF 页码和回答时的原文快照，也可以校验并查看当前仍可访问的原文。

原有普通 AI 问答、题目讲解和 PDF 题库/串讲导入继续保留。资料知识库与原来的内容导入中心是不同流程：上传到知识库不等于发布成题目或讲义。

本版上传入口仅在管理后台，是管理员维护的共享学习资料库；不支持学员私人上传、个人知识库或私有资料共享授权。

## 2. 支持的资料和限制

| 项目 | 当前行为 |
| --- | --- |
| 文件类型 | 文本型 PDF、UTF-8 TXT、Markdown（.md） |
| 文件大小 | 单文件最多 20 MiB |
| PDF 页数 | 1 至 500 页 |
| 提取文字 | 最多 200 万字符 |
| 分片 | 按原始页切分；窗口最多 800 个 Java 字符、重叠 120 个字符 |
| 原始页码 | PDF 保留真实页码，不因空白页而重新编号；TXT/MD 界面显示“文本片段”而非虚构页码 |
| 扫描件 | 无可提取文字的 PDF 明确拒绝并提示先 OCR；不内置 OCR |
| 混合 PDF | 无文字的页面不参与检索，并列出警告；需要人工确认有无扫描内容遗漏 |
| 表格、图片、公式 | 不保证完整识别版式或视觉内容；必须在发布前核对 |
| 加密和提取权限 | 拒绝加密或禁止提取内容的 PDF |

首版使用 **PostgreSQL 中文双字/英文词词法检索 + GIN 索引**，不是向量语义检索。同义表达或缺少关键词时可能漏检，可补充资料中的术语重新提问。每轮最多向模型提供 6 个检索片段。

## 3. 配置后端

沿用现有 Java 17、Maven 和 PostgreSQL 配置。启动时 Flyway 自动应用 `V11__create_knowledge_agent.sql`，创建知识库、文档、分片、智能体、关联、会话和问答轮次表。升级前备份数据库；不要手工改写已有迁移历史。

| 环境变量 | 用途 |
| --- | --- |
| `DB_URL` / `DB_USERNAME` / `DB_PASSWORD` | 现有 PostgreSQL 连接信息 |
| `ADMIN_USERNAME` / `ADMIN_PASSWORD` | 现有管理员登录配置 |
| `KNOWLEDGE_STORAGE_ROOT` | 私有原始资料目录；默认 `./data/knowledge`，生产使用独立持久化绝对路径 |
| `AI_BASE_URL` | 兼容接口的基础地址；代码会追加 `/chat/completions`，不要重复包含该路径 |
| `AI_API_KEY` | 在服务端安全注入模型密钥，不写入仓库或前端环境变量 |
| `AI_MODEL` | 服务商实际支持并已开通的模型标识；沿用现有默认值 `qwen-plus` |
| `AI_PROVIDER_NAME` | 使用日志中的服务商标识，默认 `openai-compatible` |
| `AI_DAILY_REQUEST_LIMIT` | 沿用现有每日成功请求计数限制，默认 20 |

配置结构示例，尖括号值必须替换后使用：

```bash
export KNOWLEDGE_STORAGE_ROOT=/srv/ruankao-private/knowledge
export AI_BASE_URL='https://<模型接口主机>/<兼容接口基础路径>'
export AI_MODEL='<已开通的模型标识>'
export AI_PROVIDER_NAME='<服务商标识>'
# AI_API_KEY 应由服务的安全环境配置注入，不在示例中写真实密钥。
```

运行服务的操作系统用户需要私有资料目录的读写权限。该目录必须在 Nginx、静态资源目录和公开对象存储之外；容器部署应挂载持久卷。原件以文档 UUID 命名，并通过管理员鉴权接口下载，不返回本地磁盘路径或公开原件 URL。

备份应同时覆盖 PostgreSQL 和资料目录。删除操作先撤销数据库中的文档/检索记录，再删除物理原件；若文件系统清理失败，接口会报错，可能留下不可通过知识库查询的孤立原件，需要运维核对清理。当前没有自动孤立文件回收任务。

模型请求连接超时为 10 秒、读取超时为 45 秒；小程序本轮问答请求超时为 60 秒。未配置模型或模型调用失败时返回明确错误，不伪造成功答案。无检索依据时不调用模型。

配额复用旧 AI 服务的 UTC 日界线和成功次数口径，不是所有会话之间的严格并发计费预留。使用日志保留 provider/model/function/tokens/latency/success；既有 `estimated_cost` 仍是占位零值，不能用于真实账单统计。

## 4. 构建和启动

在仓库根目录分别执行：

```bash
# 后端完整验证；集成测试需要 Docker 以运行 PostgreSQL Testcontainers。
cd server
mvn -B verify
# 安全注入上节环境变量后启动构建产物。
java -jar target/ruankao-server-0.0.1-SNAPSHOT.jar
```

```bash
# 管理后台
cd admin
npm install
npm test
npm run typecheck
npm run build
```

```bash
# 小程序
cd miniapp
npm install
npm test
npm run typecheck
npm run build:mp-weixin
```

前端继续使用各自原有的 `VITE_API_BASE_URL` 配置。生产小程序产物在 `miniapp/dist/build/mp-weixin`；还需在微信开发者工具配置实际 AppID 和允许的请求域名并进行真机验收。代理上传上限至少应容纳 20 MiB 文件及 multipart 开销，代理问答超时应与后端和客户端协调。

## 5. 问答状态、引用和并发

答案有三种明确状态：

- `GROUNDED`：模型回答使用了本轮有效引用编号。**只校验引用编号和来源身份，不等于验证答案语义正确**，仍需核对原文。
- `EXTRACT_ONLY`：模型缺少引用、引用越界或回复格式不满足要求，界面显示原文摘录，而不把模型内容伪装成完整答案。
- `NO_EVIDENCE`：资料中没有足够的检索命中，明确提示资料不足，不调用模型。

模型只能提供解释和建议，不能直接修改掌握度、题目标准答案、支付状态、会员权限或发布内容。资料和历史中的文字是上下文数据，不授予执行工具或业务写操作的能力；提示词约束不能代替人工核验。

会话归属在服务端校验，不能通过替换会话 ID 读取他人记录。每个会话最多 200 轮；模型上下文使用最近最多 6 轮的受限历史，并重新核对历史引用是否仍可访问。

客户端生成 `requestId`（UUID）。网络失败后，相同会话、相同问题复用该 ID；已成功保存的轮次直接返回，不再次调用模型。同一 ID 改成其他问题会收到 409。模型调用失败、结果未保存时重试可能再次调用服务商，不保证第三方计费的 exactly-once。

同一会话的并发请求返回 409。数据库租约为 2 分钟，并使用独立令牌防止过期请求提交或释放其他请求的租约。模型请求在数据库事务之外执行，保存答案时才执行短事务并重新检查资料状态。

撤回/删除资料后，新检索和实时原文接口不再提供该文档；禁用智能体后不再接受新问答。已有会话保留回答当时的引用快照，仍仅允许会话所属用户读取。撤回不是对历史快照的追溯删除。

## 6. 主要接口

统一采用现有 Bearer 登录鉴权。

| 范围 | 接口 |
| --- | --- |
| 管理知识库 | `GET/POST /api/v1/admin/knowledge/bases`；`PUT/DELETE .../bases/{id}` |
| 资料上传/列表 | `POST/GET .../bases/{id}/documents`，上传字段为 multipart `file` |
| 资料预览 | `GET .../documents/{id}`；`GET .../documents/{id}/chunks` |
| 发布/撤回 | `PUT .../documents/{id}/publication`，JSON `{"published":true}` 或 false |
| 删除/下载 | `DELETE .../documents/{id}`；`GET .../documents/{id}/original`，管理员专用 |
| 管理智能体 | `GET/POST .../agents`；`PUT/DELETE .../agents/{id}` |
| 学员智能体列表 | `GET /api/v1/ai/agents` |
| 会话创建/列表 | `POST/GET /api/v1/ai/agents/{agentId}/sessions` |
| 提问/历史 | `POST/GET /api/v1/ai/agents/sessions/{sessionId}/turns` |
| 实时原文 | `GET /api/v1/ai/agents/{agentId}/sources/{chunkId}` |

提问请求：

```json
{
  "requestId": "客户端生成的 UUID",
  "message": "请解释资料中的分层架构"
}
```

文档、分片、会话、轮次列表支持 `offset` 和 `limit`；合法 limit 为 1 至 100，默认值按接口分别为 50。问答页面按最多 200 轮读取完整会话。

常见失败：401 登录过期；403 无管理员权限；404 不属于当前用户或当前不可访问；409 会话忙、重试参数冲突、资料状态变化或关联约束；429 AI 配额耗尽；413 文件超限；503 模型、存储或其他服务暂不可用。

## 7. 自动化验收与上线边界

后端测试覆盖上传去重、中文检索、未发布/未关联资料隔离、真实页码、UTF-8 与扫描件拒绝、私有文件保存、引用降级、持久化历史、会话越权、请求重试、并发和租约隔离、生成期间撤回资料、模型超时、完整 HTTP 上传到引用问答流程，以及原有学习和数据库约束回归。

两个前端均有辅助逻辑测试、TypeScript/Vue 类型检查和生产构建。执行证据与提交记录见 `docs/superpowers/plans/2026-09-24-knowledge-agent-progress.md`。

自动化测试使用测试 AI Provider 和本地 HTTP 模拟端点，不需要付费模型。**代码与 CI 验证不表示已经部署到用户服务器，也不表示已完成真实模型效果评估、真实软考资料解析验收、微信真机验证或独立安全审计。**
